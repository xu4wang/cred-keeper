配置参考

config.json 的全部字段、默认值与示例。

配置文件默认在 ~/.cred-keeper/config.json（命令行 --config 可改）。路径字段都必须是绝对路径或以 ~/ 开头。修改后自动热加载。

顶层

字段默认含义
listen127.0.0.1:8790只允许回环地址；对外访问请经反向代理（如 nginx，只放行 GET/HEAD）
dataDir~/.cred-keepervault、pending、锁、state.db、日志所在目录
network.proxy—可选的 HTTP 代理；服务不读 *_proxy 环境变量
claudeBinary—要审计的 claude 二进制：每小时检查其中 client_id、接口路径、请求头是否还在，漂移则告警 contract_drift
defaults.marginMin120AT 剩余少于这么多分钟就刷新
defaults.redMin30AT 剩余少于这么多分钟：不再推迟刷新，失败告警升级
defaults.rtWarnDays7RT 剩余天数低于此值每天告警一次（RT 到期只能人工登录）
defaults.usagePollMin10用量采样间隔（分钟）
usageThresholds.fiveHourPct805 小时窗口利用率 ≥ 此值告警 usage_high
usageThresholds.projectedPct1005 小时窗口外推值 ≥ 此值告警 usage_high
alert.script—告警投递脚本；不配置就不发告警
alert.minLevelerrorinfo / warn / error / critical；低于此级别的事件只记录不投递
alert.heartbeat—每日汇总时间 HH:MM；不配置就不发心跳
alert.timeoutSec30告警脚本超时
fleet—机队模式，见机队模式。不配置 = 单机模式
注意 usage_high 是 warn 级别。alert.minLevel 保持默认 error 时，它只会记录在事件里，不会推送。想收到用量预警，就把 minLevel 调到 warn，或者用看板查看。

accounts[]

字段默认含义
id必填[a-z0-9][a-z0-9_-]{{0,31}}，本机唯一
credentialPath必填发布的凭证文件（使用方读的那份），不能与其他账号重复
label登录邮箱 @ 前部分显示名。不配置时从凭证旁的 claude 配置里读登录邮箱（~/.claude/… 对应 ~/.claude.json，其他目录对应 <目录>/.claude.json），取不到就用 id
onRefreshed—每次刷新后执行的脚本，见脚本与钩子
hookTimeoutSec60onRefreshed 超时（含 1 次重试）
preRefresh—到期后先问使用方忙不忙，exit 75 = 忙、推迟
preRefreshTimeoutSec20preRefresh 超时
preRefreshMaxDeferMin60一次推迟最长持续多久；0 = 不推迟
marginMin / redMin / rtWarnDays / usagePollMin取 defaults按账号覆盖
legacyLockDir—迁移期专用：刷新时同时持有旧 cron 的锁（mkdir + pid）。迁移完必须去掉

完整示例

{
  "listen": "127.0.0.1:8790",
  "dataDir": "~/.cred-keeper",
  "defaults": { "marginMin": 120, "redMin": 30, "rtWarnDays": 7, "usagePollMin": 10 },
  "claudeBinary": "~/.local/node-v24/lib/node_modules/@anthropic-ai/claude-code/bin/claude.exe",
  "accounts": [
    {
      "id": "default",
      "credentialPath": "~/.claude/.credentials.json",
      "onRefreshed": "~/.cred-keeper/hooks/on-refreshed-botmux-default.sh",
      "preRefresh": "~/.cred-keeper/hooks/pre-refresh-botmux.sh"
    },
    {
      "id": "acct1",
      "credentialPath": "~/accounts/acct1/claude/.credentials.json",
      "onRefreshed": "~/.cred-keeper/hooks/on-refreshed-acct1.sh",
      "preRefresh": "~/.cred-keeper/hooks/pre-refresh-acct1.sh"
    }
  ],
  "alert": { "script": "~/.cred-keeper/hooks/alert-lark.sh", "minLevel": "error", "heartbeat": "09:00" }
}
